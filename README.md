# Tailwindcss + vite tutorial

1. `npm i tailwindcss@3 @tailwindcss/vite`
2. `tailwindcss()`-t hozzáadni a pluginokhoz (vite.config.ts)
3. egyik .css-hez hozzáadni a `@import "tailwindcss";`
4. (ha a 3-as tailwindet telepítettem) futtatom az `npx tailwindcss init` parancsot (elkészül a tailwind.config.js file)
5. `npm i tailwindcss@latest`

# Feladat leírás

1. Készítsünk IAnimal interface-t állatok adatstruktúrájára. (behoztuk egy másik feladatból)
2. Készítsünk context-et állatok tárolására, hozzáadására, kedvelésére / nem kedvelésére.
3. Készítsünk routing-ot az állatok megtekintésére és hozzáadására.
4. Készítsünk komponenst ami betölti az állatokat
